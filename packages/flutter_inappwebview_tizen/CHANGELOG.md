## 0.1.0

- Initial preview release of `flutter_inappwebview_tizen`.
- Add EWK-backed `InAppWebView` support for Tizen.
- Implement navigation, JavaScript evaluation, progress/title/console callbacks, scroll, zoom, and settings subset support.
- Add cookie management with native global clearing plus JavaScript fallback for per-page operations.
- Mark `InAppBrowser` and `HeadlessInAppWebView` as explicit unsupported stubs for now.
