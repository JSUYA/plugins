## 0.1.0

- Initial preview release of `flutter_inappwebview_lwe`.
- Add LWE-backed `InAppWebView` support for Tizen.
- Implement navigation, JavaScript evaluation, progress/title callbacks, scroll, and supported settings mapping.
- Add cookie clearing through LWE and JavaScript fallback for per-page cookie operations.
- Mark `InAppBrowser` and `HeadlessInAppWebView` as explicit unsupported stubs for now.
